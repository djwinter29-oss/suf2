# Public-only PEM examples

`signing-public.pem` and `signing-test-cert.pem` contain the same example P-256
public key. The certificate is self-signed and labelled test-only.
These are format examples, not production credentials or trusted firmware keys.
Their matching private key is not shipped.

To try the packers, [generate fresh local test material](../README.md).
Do not add these example public keys to production trust stores.
